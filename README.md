### Selected work

**[KianoMIDI](https://github.com/chadedas/KianoMIDI)**<br>
Paste a link to a piano recording from YouTube, SoundCloud or 1,000+ other sites and get a `.mid` file back. Runs ByteDance's piano-transcription model on CUDA, then cleans the result: noise filtering, silence trimming and a note-range check. Windows installer under Releases, plus a [separate build](https://github.com/chadedas/KianoMIDI_OldNvidia) for older NVIDIA cards.

**[esp32SqliteSdcard](https://github.com/chadedas/esp32SqliteSdcard)**<br>
ESP32 firmware that looks up per-item motor timings in a SQLite database on an SD card and drives two stepper motors and a DC motor from them. Includes a Wi-Fi access-point page for manual control.

**[AutoLineBot](https://github.com/chadedas/AutoLineBot)**<br>
Line-following robot car on Arduino with PID steering and per-sensor calibration.

Earlier coursework: [image processing in MATLAB](https://github.com/chadedas/imageProcessing_mathlab), including a generator that renders thousands of soccer-field frames with bounding boxes, and [Snake in Java](https://github.com/chadedas/SnakeGame).
